# Rivals Script for Roblox

This script creates a rival character that follows the player in Roblox. It is designed to enhance the gameplay experience by adding a competitive element, allowing players to engage with a rival character that mimics their movements.

## Installation

1. Open Roblox Studio.
2. Create a new script in ServerScriptService.
3. Copy and paste the contents of `RivalsScript.server.lua` into the script.

## Features

- Creates a rival character for each player.
- The rival follows the player at a distance.
- The rival has a simple mesh representation.

## Usage

- The script will automatically create a rival for each player when they join the game.
- The rival will follow the player around.

## Customization

You can customize the rival's appearance and behavior by modifying the script.
